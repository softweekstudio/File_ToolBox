1. Create/open the GitHub repository for Soft Week File Toolbox.
2. Upload index.html.
3. Commit changes.
4. Settings -> Pages -> Deploy from branch -> main -> /(root).
5. Open the generated HTTPS GitHub Pages URL.
6. Do not delete the local HTML; keep it as the offline fallback.

NOTE:
A plain GitHub Pages site cannot set arbitrary COOP/COEP response headers
using only index.html. The meta tags are included as a useful baseline,
but true SharedArrayBuffer isolation must be verified in the browser.
